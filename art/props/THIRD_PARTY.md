# Third-party models in this folder

These four were supplied by Sean on 2026-10-20 as the look references for
the retro-electronics library (`tools/propgen/library.py` builds the rest
to match them). They are stored hollowed (surface voxels only, editor
chunks dropped) by `tools/propgen/hollow.py`; the originals are solid.

| File | Original | Notes |
| --- | --- | --- |
| `tv_crt.vox` | Tv_CRT.vox | 97 x 86 x 96, 611k solid voxels |
| `record_player.vox` | record_player_open.vox | 190 x 177 x 192, 1.04M |
| `micro_cassette.vox` | micro_cassette.vox | 256 cubed, 2.02M |
| `long_truck.vox` | Long_Truck.vox | 125 x 48 x 58, 201k |

**Licence: to confirm before release.** The source pack and its terms were
not recorded with the files. If they are from a CC0 pack, note it here; if
not, keep them as references only and do not ship them.
